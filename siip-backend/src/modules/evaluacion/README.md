# Evaluación

Espacio reservado para cálculos, semaforización y evaluación temática. Las reglas
recibirán valores y configuración explícitos, sin depender de Fastify ni de la BD.
Solo se habilitarán operaciones verificadas contra fichas completas; no se ejecutará
la fórmula textual como código ni se inventarán valores o reglas faltantes.
