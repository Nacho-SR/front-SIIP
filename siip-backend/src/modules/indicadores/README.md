# Indicadores

Alta, listado y consulta de fichas desde Administrador; configuración de entradas
y dependencias (SQL 006) y metodologías preparadas parte/total con umbrales,
versiones y simulación sin escrituras (SQL 007). Guardados auditados y atómicos.
Solo fichas inactivas; sin activación, vigencia, captura ni cálculo/publicación
por periodo. Los SQL requieren autorización concreta; no se aplican al iniciar.

Contratos y límites en `Documentacion/alta-indicadores.md`,
`Documentacion/variables-asignaciones.md` y `Documentacion/metodologia-indicadores.md`.
