# Indicadores

Alta, listado y consulta de fichas documentales desde Administrador. Ficha y
auditoría atómicas; siempre inactivas al crear. SQL 005 prepara agrupaciones,
familias e indicadores y debe aplicarse en la base autorizada. No implementa
variables operativas, captura, edición/activación ni cálculo por periodo.
Contrato y límites: `Documentacion/alta-indicadores.md` en la raíz del repositorio.
